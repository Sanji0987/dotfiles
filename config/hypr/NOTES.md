# Hyprland configuration — `~/.config/hypr`

Hyprland 0.56.2 on CachyOS, using the **Lua config format** (not `hyprland.conf`).
Single monitor `DP-2` (HP OMEN 27 G2, 1920x1080@179.98Hz, scale 1, on the
RTX 5070 Ti / `card1`; the Intel Arrow Lake iGPU is `card0`). Desktop PC — the
only idle behaviour anywhere in this setup is a 15-minute lock. No DPMS, no
dimming, no suspend, by design.

The UI is a handful of small daemons — waybar, mako, swayosd, hyprpaper, rofi —
each started from `conf/autostart.lua` and each killable on its own. This
replaced Omarchy 4's Quickshell shell, which hosted all of it in one QML
process. See `~/dotfiles/README.md` for that story.

The look is deliberately colourless: near-black surfaces carried by alpha, two
greys for borders, one blue used only for selection, and the wallpaper
(`~/Pictures/Wallpapers/rainynight-1.png`) supplying whatever colour there is.

```

├── NOTES.md           this file
├── hyprland.lua       entry point — only `require` calls, nothing else
├── hyprlock.conf      lock screen (hyprlock, hyprlang syntax, NOT Lua)
├── hyprpaper.conf     wallpaper daemon (hyprlang syntax, NOT Lua)
├── hypridle.conf      idle daemon — lock only, no DPMS/suspend (hyprlang)
├── hyprsunset.conf    colour temperature, fixed 5700K (hyprlang)
└── conf/
    ├── palette.lua     the desktop palette + mix()/rgba(), as a module
    ├── colors.lua      legacy wallpaper palette, group bars only, as a module
    ├── programs.lua    default apps + paths, returned as a module
    ├── display.lua     monitor, cursor, misc compositor behaviour
    ├── peripherals.lua keyboard, mouse, touchpad, gestures
    ├── theme.lua       borders, gaps, rounding, blur, group bars
    ├── animations.lua  bezier/spring curves and per-leaf animation timings
    ├── layouts.lua     dwindle / master / scrolling layout behaviour
    ├── rules.lua       window, workspace and layer rules
    ├── keybinds.lua    every keybinding
    ├── autostart.lua   session env vars + processes started with the session
    └── themes/         dormant look overrides — nothing here is loaded
```

`hyprland.lua.bak` is the original autogenerated single-file config, kept as a
fallback.

## How the Lua config works

- Hyprland 0.56 reads Lua **natively**. There is no generator and no
  intermediate `hyprland.conf`: these files are executed in-process at config
  load, and re-executed on `hyprctl reload`.
- Hyprland exposes a global `hl` table. Files are plain Lua.
- `require("conf.display")` resolves to `~/.config/hypr/conf/display.lua` — the
  config directory is on `package.path`, and Lua turns the dot into a directory
  separator.
- Modules that `return` a table (`palette.lua`, `colors.lua`, `programs.lua`)
  are consumed with `local t = require("conf.palette")`. Modules that call
  `hl.*` are required for their side effects only.
- Load order is the order of `require` in `hyprland.lua`. Later `hl.config({...})`
  calls merge over earlier ones, so keep `theme` before `rules` — rules override
  theme values per window.

### API used here

| Call | Purpose |
|---|---|
| `hl.config({ section = { key = value } })` | set config values; nested tables map to `section:key` |
| `hl.monitor({...})` | monitor declaration |
| `hl.env(name, value)` | session environment variable |
| `hl.bind(keys, dispatcher, opts)` | keybinding; `opts` takes `mouse`, `locked`, `repeating` |
| `hl.dsp.*` | dispatchers — `exec_cmd`, `exit`, `focus`, `layout`, `window.*`, `workspace.*` |
| `hl.window_rule / hl.workspace_rule / hl.layer_rule` | rules, each takes a `name` and a `match` table |
| `hl.curve(name, {...})` / `hl.animation({ leaf = ... })` | animation curves and timings |
| `hl.gesture({...})` | touchpad gestures |
| `hl.on("hyprland.start", fn)` | run a function at session start |
| `hl.exec_cmd(cmd)` | run a command directly (as used inside `hl.on`), as opposed to `hl.dsp.exec_cmd`, which *returns* a dispatcher for `hl.bind` |

### Gotchas learned the hard way

1. **Unknown config keys fail silently** — nothing is printed at load, and
   `hyprctl configerrors` is the only way to see them. `misc:vfr` and
   `misc:new_window_takes_over_fullscreen` do *not* exist in 0.56 and were
   rejected this way.
2. **`hl.layer_rule` is the exception: it *does* validate field names.** The
   blur threshold field is `ignore_alpha` (a 0..1 threshold — pixels below it
   are left unblurred). hyprlang's old `ignorezero` does not exist here, and
   `ignore_zero` is rejected outright and shows up in `hyprctl configerrors` —
   which is how this was found. Do not assume the silent-failure rule above
   applies to layer rules.
3. **Colours are strings, built by concatenation.** `conf/colors.lua` stores
   bare hex (`"060709"`), so the closing paren belongs *inside* the last string:
   `"rgba(" .. c.black .. "b0)"` ✅ — `"rgba(" .. c.black .. "b0")` ✗ (stray
   paren, Lua syntax error). `conf/palette.lua` avoids this by wrapping in
   `M.rgba()` instead.
4. **A bare word is a nil global.** The original config had
   `accel_profile = flat`, which silently evaluated to `nil` and never applied.
   Quote enum values.
5. After any edit: `hyprctl reload && hyprctl configerrors`. Empty output = clean.

## File-by-file

### `hyprland.lua`
Entry point. Eight `require` lines, no configuration of its own. Add a new area
by creating `conf/<area>.lua` and adding one `require` here.

### `conf/palette.lua`
The desktop palette and the two helpers that shape it into Hyprland's colour
forms. A **static module**: the values are literals in the file, generated by
nothing and read out of no theme state.

| Key | Value | Used for |
|---|---|---|
| `accent` | `#0860f2` | selection only |
| `background` | `#000000` | surfaces, always via alpha |
| `foreground` | `#dedede` | text |
| `border_active` | `#707070` | focused window border |
| `border_inactive` | `#393939` | unfocused window border |

Plus `mix(a, b, amount)` (blend two `#rrggbb` strings) and `rgba(hex, alpha)`
(`"#rrggbb"` + `"ff"` → `"rgba(rrggbbff)"`, the form Hyprland wants).

This replaced `conf/omarchy.lua`, which parsed the active Omarchy theme's
`colors.toml` at config-load time. There is no theme state left to read.

`mix()` currently has no caller — the borders are two flat greys, not a
gradient. It is kept because it is three lines and the next border experiment
will want it.

### `conf/colors.lua`
The old palette sampled from the `linus.png` wallpaper. Only four keys are
still consumed, all by the group-bar block in `theme.lua`: `slate` (`2c3748`,
active tab), `black` (`060709`, inactive tab), `cream` (`e7e6cf`, tab text) and
`red` (`a4696a`, locked group). **Bare hex, no `#`, no `rgba()`** — callers
wrap it, which is gotcha 3 above. Everything else in the table is unreferenced.

### `conf/programs.lua`
Returns default applications and paths so `keybinds.lua` and `autostart.lua`
agree: `terminal = kitty`, `fileManager = dolphin`, `menu = "rofi -show drun"`,
`lock = hyprlock`, `shotDir = "$HOME/Pictures/Screenshots"` (left unexpanded
because it is used inside a shell command string). Toggling the launcher is
done in `keybinds.lua`, not here.

### `conf/display.lua`
- `hl.monitor` — DP-2, `1920x1080@179.98Hz`, position `0x0`, scale 1.
- `HYPRCURSOR_THEME = "Capitaine Cursors"`, `HYPRCURSOR_SIZE = 20`. The
  `XCURSOR_*` pair is commented out; `autostart.lua` re-applies the same theme
  and size at session start with `hyprctl setcursor`.
- `cursor:inactive_timeout = 0` and `hide_on_key_press = false` — the pointer
  never auto-hides. Deliberate: this is a desktop, nothing should time out.
- `misc` — mascot wallpaper and splash off (hyprpaper owns the background),
  `focus_on_activate` on.

### `conf/peripherals.lua`
- `accel_profile = "flat"` with `sensitivity = 0` — raw 1:1 mouse input, no
  acceleration.
- `repeat_rate 35` / `repeat_delay 200`, numlock on at login, `follow_mouse = 1`.
- Touchpad block (natural scroll, tap to click, disable while typing) is
  harmless on a desktop and there for when a touchpad is attached.
- Three-finger horizontal swipe switches workspaces.
- Per-device overrides would go here as `hl.device({ name = "...", sensitivity = ... })`.

### `conf/theme.lua`
The whole window look. As configured nothing merges over it — this file *is* the
look. Requires `conf.palette` as `t` and `conf.colors` as `c`.

- **Borders: 1px, two flat greys.** `#707070` focused, `#393939` not. Focus is a
  brightness step between neutrals, so nothing competes with the wallpaper. 2px
  was right when the border was near-black and needed the weight; against these
  greys a hairline is enough.
- **Gaps: `gaps_in = 4`, `gaps_out = 12`.** `gaps_in` is applied to each side, so
  adjacent windows show 8px between them against a 12px margin to the screen
  edge — the tiling reads as cards on a wallpaper rather than panes in a frame.
- `rounding = 10`, `rounding_power = 2`.
- **Nothing is translucent and nothing dims.** `active_opacity`,
  `inactive_opacity` and `fullscreen_opacity` are all `1.0`, and
  `dim_inactive = false` — translucent app windows over a busy wallpaper read as
  muddy, and dimming on top of the border greys is two signals for one thing.
- **No shadow.** At 1px borders and 10px rounding it only muddies the gap.
- **Blur: size 12, 3 passes**, `ignore_opacity`, `noise 0.012`,
  contrast/brightness both `1.0`, `vibrancy 0.18`, popups blurred with
  `popups_ignorealpha 0.4`. Wide and soft enough that the wallpaper behind a
  panel becomes colour rather than shapes. `xray` is off globally here and
  turned on per-layer for waybar in `rules.lua`.
- `resize_on_border` + `extend_border_grab_area = 12` — makes a thin border
  grabbable.
- Group bars (tabbed groups) take the same grey border as ordinary windows; the
  bar itself still uses the old `colors.lua` values (`slate` active, `red` locked).

### Themes

`conf/themes/` is gone. A theme is now a directory under `config/themes/`, and
`config/themes/current` is a symlink naming the active one:

| file | reaches Hyprland through |
|---|---|
| `palette.lua` | `conf/palette.lua`, a shim that `dofile`s it |
| `look.lua` | the tail of `conf/theme.lua` |

Both use `dofile`, not `require`, deliberately: `require` caches by module name,
so after a theme switch a `hyprctl reload` would keep serving the previous
theme's table out of `package.loaded`.

`apple-stock/look.lua` is intentionally empty — `theme.lua`'s own values *are*
that look. `rainynight/look.lua` carries rounding 14, 0.93/0.92 opacity and
indigo borders.

Switching is `theme-set <name>` (or `SUPER+SHIFT+T` for the picker), which
repoints the symlink and reloads. Unlike before, the rest of the desktop **does**
follow: waybar, rofi, swayosd and hyprlock all read through the same symlink,
and mako and kitty are copied because neither supports an include.

### `conf/animations.lua`
Hyprland's default curve set (`easeOutQuint`, `easeInOutCubic`, `linear`,
`almostLinear`, `quick`, plus the `easy` spring) and per-leaf timings. Fast and
understated — window open/close uses the spring with `popin 87%`, workspaces
cross-fade. Nothing here is palette-specific; safe to retune freely.

### `conf/layouts.lua`
`dwindle` is the active layout (set in `theme.lua` via `general:layout`).
`preserve_split` and `smart_resizing` on, `force_split = 2` so new windows
always open to the right/below rather than following the cursor. `master` and
`scrolling` blocks are configured but unused unless the layout is switched.

### `conf/rules.lua`
Reads top to bottom: window rules, then workspace rules, then layer rules.

- `suppress-maximize-events` — ignores maximize requests from every app.
- `fix-xwayland-drags` — the standard empty-class/empty-title XWayland drag fix.
- `float-dialogs` — file pickers float, 900x600, centred.
- `games-raw` — matches `steam_app_*`, `cs2`, `gamescope`, `hl2_linux`, `*.exe`
  and disables blur, dim, shadow and animations. Keeps the compositor out of the
  way in games.
- `pip-on-top` — Picture-in-Picture floats and pins.
- `move-hyprland-run` — carried over from the original config.
- **Smart gaps**: `f[1]` (single fullscreen) gets `gaps_in/out = 0` and the
  matching window rule drops `border_size` and `rounding` to 0, so fullscreen
  really is edge-to-edge. `w[tv1]` (single tiled window) used to do the same and
  no longer does — losing the gaps *and* the border on the commonest layout of
  all undid both of them.
- **Layer rules** now name the real surfaces and, for the first time, blur them:

  | Rule | Namespace | Effect |
  |---|---|---|
  | `blur-bar` | `waybar` | `blur`, `ignore_alpha = 0.2`, `xray = true` |
  | `blur-surfaces` | `^(rofi\|notifications\|swayosd)$` | `blur`, `ignore_alpha = 0.2` |
  | `blur-selection` | `^selection$` | `no_anim` (slurp) |

  `xray` on the bar samples the wallpaper rather than the windows underneath, so
  it keeps one steady look instead of smearing whatever scrolls beneath it.
  `ignore_alpha = 0.2` leaves the transparent margins around a bar or a toast
  unblurred, so they do not paint a blurred slab, while the surface's own
  translucent background still frosts.

  Blur was deliberately *off* for the Quickshell layers, and the recorded reason
  was sound: `omarchy-background` and `omarchy-notifications` were full-screen
  layers, so blurring them blurred the whole screen rather than the toast. None
  of the replacements is full-screen except the wallpaper, which is not matched.
  `hyprctl layers` is the check for what is actually up.

### `conf/keybinds.lua`
`mainMod = SUPER`. Requires `conf.programs`.

| Bind | Action |
|---|---|
| `SUPER + Return` | kitty |
| `SUPER + E` | dolphin |
| `SUPER + Space` | rofi — `pkill -x rofi \|\| rofi -show drun`, so it toggles rather than stacking |
| `SUPER + W` | close window |
| `SUPER + F` | toggle float |
| `SUPER + P` | pseudo |
| `SUPER + J` | toggle split |
| `SUPER + Shift + M` | exit Hyprland |
| **`SUPER + Shift + L`** | **lock (hyprlock)** — guarded by `pidof` so it cannot stack |
| `SUPER + Shift + S` | region screenshot (`slurp`) |
| `SUPER + Shift + PgUp` | full-screen screenshot |
| `Print` | full-screen screenshot (alias of the above) |
| `SUPER + V` | clipboard history — `cliphist list \| rofi -dmenu -p Clipboard \| cliphist decode \| wl-copy` |
| `SUPER + ←↑↓→` | move focus |
| `SUPER + 1..0` | workspaces 1–10 (10 is on key `0`) |
| `SUPER + Shift + 1..0` | move window to workspace |
| `SUPER + S` | toggle special workspace `magic` |
| `SUPER + Alt + S` | move window to special workspace `magic` |
| `SUPER + scroll` | cycle workspaces |
| `SUPER + LMB / RMB` | drag / resize window |
| XF86 volume + mic mute | `swayosd-client --output-volume …` / `--input-volume mute-toggle`, `locked`, `repeating` |
| XF86 media keys | `swayosd-client --playerctl next/prev/play-pause`, `locked` |
| XF86MonBrightness Up/Down | `ddcutil --noverify setvcp 10 ± 5`, `locked`, **not** repeating |

Screenshots write a timestamped PNG to `~/Pictures/Screenshots` **and** put it on
the clipboard in one go, via `tee`. `SUPER + Shift + PgUp` is bound as `Prior` —
that is what xkbcommon calls Page_Up and what Hyprland parses. The special
workspace move was on `SUPER + Shift + S` until the region screenshot took that
chord.

Volume and media go through `swayosd-client` rather than raw `wpctl`/`playerctl`
because it makes the change *and* draws the on-screen pill in one command.
Brightness deliberately does **not**: `swayosd-client --brightness` goes through
`brightnessctl`, which needs a `/sys/class/backlight` device this desktop does
not have. So brightness stays on **DDC/CI** via `ddcutil`, and simply has no OSD.
`ddcutil` reaches the OMEN 27 G2 on `/dev/i2c-4` (`ddcutil detect` to confirm;
the `i2c-dev` module is loaded and the user's group membership already allows
access). Each call is a ~1s i2c round trip, which is why `repeating` is off —
key repeat would queue dozens of writes.

Note when editing: `--dmenu` inside a command string is a CLI flag, not a Lua
comment. A careless comment-stripping regex will eat it and break `SUPER + V`.

### `conf/autostart.lua`
Environment variables (`XDG_CURRENT_DESKTOP=Hyprland`, `QT_QPA_PLATFORMTHEME=kde`,
Qt decoration off, Electron Ozone auto, Firefox Wayland) then
`hl.on("hyprland.start")`, in this order:

| Process | Role |
|---|---|
| `waybar` | bar |
| `mako` | notifications |
| `swayosd-server` | volume / media OSD |
| `hyprpaper` | wallpaper |
| `gsr-ui launch-hide-announce` | GPU Screen Recorder UI, started hidden |
| `hyprctl setcursor Capitaine Cursors 20` | cursor theme, re-applied at start |
| `hyprsunset` | colour temperature, reads `hyprsunset.conf` |
| `hypridle` | idle → lock only, reads `hypridle.conf` |
| `wl-paste --watch cliphist store` | clipboard history recorder |
| `wl-clip-persist --clipboard regular` | keeps clipboard contents after the source app exits |
| `dex -a` | XDG autostart entries |
| `/usr/lib/polkit-kde-authentication-agent-1` | polkit auth prompts |

The first four replaced the single `omarchy-shell-run` line. One QML process
hosted the bar, notifications, OSD and wallpaper, so a crash or a qt6 bump took
the whole desktop's UI with it; now any one of them can be killed and restarted
alone.

The polkit path ends in **`-1` (one)**, not `-l` (letter L). The original config
had the letter and no auth agent ever started.

### `hyprlock.conf`
hyprlang syntax, not Lua. Colours are **literals** at the top of the file
(`$color`, `$inner_color`, `$outer_color`, `$font_color`, `$placeholder_color`,
`$check_color`), and they are the same neutral set as `conf/palette.lua` —
black carried by alpha, the `707070` grey on the outline, white text and the
`0860f2` blue on the check state. They used to be `source`d from the active
theme's own `hyprlock.conf`; that state directory is gone, so this file owns its
look and is edited by hand. The background is
`~/Pictures/Wallpapers/rainynight-1.png` — the same file hyprpaper draws —
blurred 3 passes at 0.55 brightness, which is what lets a white clock sit on a
busy pixel-art background.

Layout: hour over minute at 190pt in `Inter ExtraBold`, a 230x2 `shape` rule,
weekday and `%d %b`, the current track, a lock glyph, a pill input field
(`rounding = -1`) and `$USER` in italics. `hide_cursor` and
`ignore_empty_input` on.

Three font variables, not two: `$font` (Inter) and `$font_bold` (Inter
ExtraBold) for text, and **`$font_icon` (JetBrainsMono Nerd Font) for the glyph
labels**. Inter has no Nerd Font codepoints, so the lock glyph and the input
placeholder render as tofu if they follow `$font`.

Two traps:
- Pango markup needs `##` to escape a literal `#`.
- **hyprlang reads `{{ }}` as an arithmetic expression**, so `playerctl --format
  '{{title}}'` fails to parse with *"Invalid expression type: supported +, -, *, /"*.
  Hence `playerctl metadata title`, which needs no braces.

There is no `--dry-run`, but `hyprlock --display <bogus>` parses the config and
reports its errors before asserting on the missing compositor — that is the
offline syntax check, and it beats locking yourself out to find a typo.

### `hyprpaper.conf`
hyprlang syntax. `preload` plus one `wallpaper { }` block: `monitor = DP-2`,
`path = ~/Pictures/Wallpapers/rainynight-1.png`, `fit_mode = cover`, with
`splash = false` and `ipc = on`. Verify with `hyprctl hyprpaper listactive`.

This file was dead weight while Quickshell painted the background from its own
full-screen layer, and went stale in the meantime — it still named `DP-1` and the
old `linus.png`. It is live again and owns the wallpaper. `ipc = on` means the
image can be swapped at runtime with `hyprctl hyprpaper wallpaper "DP-2,<path>"`.

### `hypridle.conf`
hyprlang syntax. Deliberately minimal: **one** listener, 900s →
`loginctl lock-session`. hypridle binds `hyprland_lock_notifier_v1` and handles
the logind Lock signal itself, so `loginctl lock-session` routes back to
`general:lock_cmd` (`pidof hyprlock || hyprlock`) — the same guarded invocation
as `SUPER + Shift + L`. That single path means the keybind and the idle timeout
can never end up with two different lock behaviours.

There is intentionally **no** DPMS listener, no dimming and no
`systemctl suspend`, and **no** `before_sleep_cmd`/`after_sleep_cmd` — this is a
desktop and the standing instruction is no power management. Only add those back
if explicitly asked. hypridle still takes a logind sleep inhibitor on startup
(`Inhibited sleep with fd N` in its log); that is a side effect of it registering
as a sleep handler and it makes the machine *less* likely to suspend, not more.

### `hyprsunset.conf`
hyprlang syntax. `max-gamma = 150` plus a single `profile { }` at `time = 00:00`,
so 5700K is applied all day rather than on a day/night schedule — slightly warmer
than the 6500K sRGB white point without an orange cast.

**Gotcha:** `gamma` inside a profile is a *multiplier*, not a percentage.
`gamma = 100` is parsed as 10000% and hyprsunset refuses to start with
`Gamma invalid: 10000%`. Use `gamma = 1.0` for neutral. The CLI flag `--gamma`
takes a percentage, which is where the confusion comes from.

Runtime control without editing the file:
`hyprctl hyprsunset temperature` reads it, `hyprctl hyprsunset temperature 6500`
sets it, `hyprctl hyprsunset identity` disables the shift entirely.

## Where the colours live

There is no theme pipeline and nothing is generated. Every palette in the repo
is a tracked static file, and they are kept in step **by hand** — editing one
means editing the others:

| File | What it colours |
|---|---|
| `conf/palette.lua` | window borders, via `conf/theme.lua` |
| `hyprlock.conf` | lock screen (same neutral set, written as `rgba(r, g, b, a)`) |
| `~/dotfiles/config/waybar/style.css` | bar |
| `~/dotfiles/config/mako/config` | notifications |
| `~/dotfiles/config/rofi/spotlight.rasi` | launcher |
| `~/dotfiles/config/swayosd/style.css` | volume / media HUD |
| `~/dotfiles/config/kitty/current-theme.conf` | terminal (and fastfetch, through the ANSI names) |

`~/.config/kitty/kitty.conf` sets `background_opacity 0.75` and 8px padding, so
Hyprland's blur shows through the terminal.

Caveat: `config/swayosd/` exists in the repo but is **not symlinked** into
`~/.config/swayosd`, so swayosd is still drawing stock GTK grey under a blurred
layer. The full repo-level list is in `~/dotfiles/README.md`.

## Verifying changes

```sh
hyprctl reload && hyprctl configerrors     # empty output = clean
hyprctl getoption general:border_size      # check a specific value took effect
hyprctl binds -j | jq length               # binds registered (53 currently)
hyprctl layers                             # which layer surfaces are actually up
hyprctl monitors -j | jq -r '.[].name'     # should print DP-2
hyprctl hyprpaper listactive               # wallpaper in place
hyprctl hyprsunset temperature             # should print 5700
pkill hypridle; hypridle                   # hypridle has no reload; restart to apply
pkill waybar; waybar &                     # same for the bar
makoctl reload                             # mako does reload in place
```

Kitty colour changes only apply to newly opened windows.
